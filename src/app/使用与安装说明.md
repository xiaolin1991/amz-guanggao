## 二、 极速安装指南（以 Chrome / Edge 为例）

### 方式一：CRX 文件一键拖拽安装（推荐）
1. 打开浏览器扩展管理页面：
   * **Chrome 浏览器**：地址栏输入 `chrome://extensions/` 并回车。
   * **Edge 浏览器**：地址栏输入 `edge://extensions/` 并回车。
2. 确保页面右上角的 **“开发者模式” (Developer mode)** 开关处于**开启**状态。
3. 直接将 **`晓林广告助手_v1.2.0.crx`** 文件拖拽到该扩展页面中。
4. 在弹出的确认窗口中点击 **“添加扩展程序”** 即可完成安装！

---

### 方式二：文件夹 / ZIP 解压加载安装
1. 打开浏览器扩展管理页面（`chrome://extensions/`），开启右上角 **“开发者模式”**。
2. 点击左上角 **“加载已解压的扩展程序” (Load unpacked)**。
3. 选择解压出的工程文件夹：`c:\Users\Administrator\Downloads\amazon广告优化\xiaolin-ad-assistant`。
4. 安装完成！浏览器右上角会出现 **“晓林广告助手”** 的透明盾牌徽标。

## 三、 v1.2.0 针对性问题深度攻坚与核心突破

### 1. 突破虚拟滚动（Virtual DOM List）：未下拉的行也能全部抓取！
* **技术突破**：亚马逊后台广告列表采用 React 虚拟滚动，屏幕外的 DOM 会被后台销毁。
* **全新引擎**：
  * **全局记忆池 (`XiaolinRowStore`)**：无论亚马逊后台怎么销毁已滚动的 DOM 节点，插件的全局记忆池永久锁定所有扫描到的关键词数据，绝不丢失。
  * **【⚡ 快扫全表】闪扫引擎**：打开页面 2.2 秒后（或随时点击面板右上角的 **[⚡ 快扫全表]**），插件会在底层以 300 毫秒完成微步轻扫，瞬间将整页 50~100 个关键词全部抓取进面板！
  * **动态平滑监听**：卖家正常向下滚动翻阅时，插件防抖监听器自动在后台静默补录新出现的行，做到 100% 全覆盖。

### 2. 新增【🎯 定位】按钮：一键滚动并金色高亮目标关键词
* **卖家痛点**：在插件面板中看到建议，但不确定这个词在后台哪一行、什么表现。
* **全新功能**：在【🛑 降价止损】和【🚀 曝光激活】列表的每个关键词右侧，均配备 **`[🎯 定位]`** 按钮。
* **视觉交互**：点击后页面瞬间平滑滚动并将对应行居中，并触发持续 2.5 秒的**金色流光呼吸脉冲（Golden Pulse）**，一眼即可精确定位！

### 3. 彻底根治“误填入点击量列”与“建议竞价混淆”
* **技术重构**：
  * 全局动态表头嗅探器严格区分 `关键词/投放`、`匹配方式`、`建议竞价`、`竞价`、`展现量`、`点击量`、`花费`、`销售额`。
  * 竞价修改逻辑**锁定且仅能操作真实的 `竞价 (Bid)` 列**，严禁触碰任何其他列（如点击量）。
  * 自动触发 React 原生状态通知与 Enter 确认，完美适配亚马逊前端数据绑定。

### 4. 彻底解决 570 / 77 展现量误报为“曝光不足”
* **原因排查**：亚马逊千分位分隔符 `4,181` 在旧逻辑中被误解为欧洲小数 `4.181`（< 5），同时列偏移导致把 CPC / 建议出价误当做曝光量。
* **彻底修复**：重写千位分隔符解析器并提高校验权重，570、77、4,181 次展示量均 100% 准确识别；曝光激活门槛严格遵循 `< 5 次`，绝不再出现误判！

### 5. 【🛑 降价止损】卡片格式全面统一
* 降价止损卡片与曝光激活完全统一为标准交互：
  * 显示：`[关键词] [🎯 定位] [徽章]`
  * 调价：`原竞价 US$X.XX ➔ 建议降至: [US$ 自定义输入框] [应用修改]`
  * 支持自定义修改任何单条建议，也可以在顶部一键 **[⚡ 批量应用降价]**！

### 6. 悬浮启动图标自由拖拽 + 位置记忆（彻底杜绝遮挡）
* **痛点解决**：此前图标固定在屏幕右下角，容易遮挡表格翻页器或最后几行数据。
* **全新交互**：
  * **丝滑自由拖拽**：鼠标左键按住圆形启动图标，可将其拖动到屏幕任意空白位置，松手即停；
  * **自动边缘与视口保护**：具备安全边界计算，图标绝对不会被拖到屏幕可视区域之外；
  * **位置持久化记忆**：拖拽到新位置后，系统会自动保存坐标，刷新网页或重新打开后依然保留在您最舒适的位置；
  * **智能点击防误触**：微移动（< 4px）视为单击正常展开面板，滑动拖拽松开后自动阻止误弹窗。
