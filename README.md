# Amazon 广告智能止血调价助手 (Bulk Sheet Optimizer)

专为亚马逊卖家量身定制的**轻量化、高隐私、自动化广告诊断与调价工具**。无需繁琐申请亚马逊 Ads API 开发者授权，直接通过**官方批量操作表（Bulk Operations / Search Term Report）**，在浏览器本地 1 秒识别吸血亏损词，智能核算保本出价，一键导出修改表重新传回后台生效。

---

## 🌟 核心功能与亮点

- **🩸 1秒找出吸血无效词（精准止血）**：
  自动扫描所有广告活动中点击超过阈值（如 ≥10 次）却 0 订单的垃圾关键词与蹭流量竞品 ASIN，生成精准否定建议，堵住资金漏洞。
- **📉 动态保本出价算法（科学降价）**：
  根据你设定的**目标保本 ACOS（如 25%）**与实际 CPC，利用公式动态核算保本出价：
  $$\text{建议出价} = \text{实际 CPC} \times \frac{\text{目标 ACOS}}{\text{当前 ACOS}}$$
  并提供单次降幅保护，防止断崖式降价导致Listing断流。
- **⭐ 优质搜索词收割（拓词增效）**：
  从自动广告、广泛匹配中提炼高转化、低 ACOS 的黄金词，建议移入独立「精准匹配 Manual Exact」广告组。
- **🛡️ 100% 浏览器本地解析（数据绝对安全）**：
  纯前端单页架构（SPA），所有 Excel 表格的读取、计算与导出全部在卖家自己的浏览器内存沙盒中进行，**绝不向任何外部服务器上传**店铺与广告机密。
- **📖 内置保姆级后台操作指南**：
  手把手教学：如何 3 步在亚马逊后台下载正确的批量表（规避 48 小时延迟归因误判），以及优化后如何传回后台 1 分钟全局生效。

## 🚀 部署指南（GitHub + Cloudflare Pages）

本项目完全静态化，推荐使用 **Cloudflare Pages** 进行免费托管部署：

### 方式一：Cloudflare Pages 自动化部署（推荐）
1. 将本项目代码 Push 到你的 GitHub 仓库。
2. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)，在左侧导航进入 **Workers 和 Pages (Workers & Pages)**。
3. 点击 **创建应用程序 (Create application)** $\to$ 选择 **Pages** $\to$ 点击 **连接到 Git (Connect to Git)**。
4. 选择你的 `amz-guanggao` 仓库，设置如下构建参数：
   - **框架预设 (Framework preset)**: `Vite`
   - **构建命令 (Build command)**: `npm run build`
   - **构建输出目录 (Build output directory)**: `dist`
5. 点击 **保存并部署 (Save and Deploy)**，等待 1 分钟即可获得全球 CDN 秒开的专属网页地址！

### 方式二：本地运行
```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务
npm run dev

# 3. 浏览器打开 http://localhost:5173 即可使用
```

## 📋 卖家实战操作闭环

1. **导出报表**：
   登录卖家平台 $\to$ 广告 $\to$ 广告活动管理 $\to$ 批量操作 (Bulk operations) $\to$ 选择过去 30 天/60 天（勾选“排除过去48小时”） $\to$ 点击“创建用于下载的电子表格”。
2. **诊断优化**：
   将下载好的 `.xlsx` 表格拖入本网页，滑动调节你的目标 ACOS，核对系统给出的【否定清单】与【降价清单】。
3. **一键导出**：
   点击「一键导出亚马逊 Bulk 批量更新表 (.xlsx)」。
4. **后台生效**：
   回到亚马逊批量操作页面，在“上传电子表格”区域提交修改后的文件，1 分钟内所有广告出价与否定词全局生效！
